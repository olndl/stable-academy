# План

Делаем приложение для Android и iPhone на React Native + Expo. Идём по одному дню за раз, следующий день начинаем по запросу.

Интерфейс простой: системные шрифты, обычные кнопки и списки. Без декоративных иллюстраций и сложного дизайна.

## Неделя 1

- [x] День 1 — Expo + React Native + TypeScript, ESLint, Prettier, общий layout и нижние вкладки через Expo Router.
- [x] День 2 — типы Course, Lesson, Trainer, данные курсов и MSW 2.15 через getResponse. Демо-API доступен в production и без отдельного сервера; native-бандлы проверены.
- [x] День 3 — каталог через TanStack Query, FlatList, карточки, загрузка и ошибки.
- [x] День 4 — поиск и фильтры по дисциплине и уровню, параметры маршрута Expo Router для сохранения фильтров при переходах.
- [x] День 5 — экран курса и список уроков.

## Неделя 2

- [x] День 6 — Redux store и списки: хочу посмотреть, в процессе, пройдено.
- [x] День 7 — плеер expo-video, пройденные уроки, прогресс, продолжение просмотра.
- [x] День 8 — сохранение состояния в AsyncStorage и восстановление после перезапуска.
- [x] День 9 — оценки и короткие отзывы.
- [x] День 10 — дневник: валидация, создание, редактирование и удаление записей, работа с клавиатурой.

## Неделя 3

## На потом

Офлайн-видео, DE/EN, Supabase, публикация в магазинах. Пока не входят в основной объём. Веб-деплой и Vercel не используем.

## Рабочий процесс

На каждую задачу — отдельная ветка и Pull Request в main. Ветки и коммиты: `feature/{name}`, `fix/{name}`, `test/{name}`, `docs/{name}`, `chore/{name}` по типу изменения. Даты настоящие, без переноса задним числом. Добавляем только то, что реально сделано в этот день.
