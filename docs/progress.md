День 1: основа готова. Vercel не используем. Для запуска: Node 24, npm start, QR-код открыть в Expo Go на телефоне в той же Wi-Fi сети.

Следующий шаг: день 2 — типы Course, Lesson, Trainer, данные курсов и моковый API.

## День 2 — 26 октября 2026

Сделано:

- Типы Course, Lesson, Trainer, дисциплины и уровни.
- 6 курсов, 4 вымышленных тренера и 18 уроков.
- MSW-обработчики для списка курсов, курса, урока, списка тренеров и тренера. Для неизвестных id — 404.
- Типизированные функции API, ApiError со статусом и отмена через AbortSignal.
- API-тесты на встроенном Node test runner. Полные тесты интерфейса на Jest остаются на день 12.
- Уже установленные Reanimated и Worklets зафиксированы в версиях из Expo SDK 57.

MSW: пакет @msw/react-native из актуальной документации вернул 404 в npm. Используется опубликованная MSW 2.15.0 и её публичная функция getResponse(). Наш mockFetch передаёт Request обработчикам и получает Response прямо в процессе приложения. Это демо-транспорт, а не перехват глобального fetch. Внешние запросы не подменяются, отдельный сервер и service worker не нужны. Включение не зависит от **DEV** или NODE_ENV. При подключении настоящего сервера достаточно заменить транспорт в src/api/request.ts.

Проверки: 11 API-сценариев на стандартных fetch-классах и ещё 11 на whatwg-fetch, который используется React Native. Оба набора проходят с NODE_ENV=production, включая тест без доступа к сети. ESLint, TypeScript, форматирование, полный экспорт приложения и отдельные production-бандлы с импортированным API для Android/iOS прошли. На устройстве и в Hermes пока не запускалось.
