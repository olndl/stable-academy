## День 2 — 26 октября 2026

Сделано:

- Типы Course, Lesson, Trainer, дисциплины и уровни.
- 6 курсов, 4 вымышленных тренера и 18 уроков.
- MSW-обработчики для списка курсов, курса, урока, списка тренеров и тренера. Для неизвестных id — 404.
- Типизированные функции API, ApiError со статусом и отмена через AbortSignal.
- API-тесты на встроенном Node test runner. Полные тесты интерфейса на Jest остаются на день 12.
- Уже установленные Reanimated и Worklets зафиксированы в версиях из Expo SDK 57.

MSW: пакет @msw/react-native из актуальной документации вернул 404 в npm. Используется опубликованная MSW 2.15.0 и её публичная функция getResponse(). Наш mockFetch передаёт Request обработчикам и получает Response прямо в процессе приложения. Это демо-транспорт, а не перехват глобального fetch. Внешние запросы не подменяются, отдельный сервер и service worker не нужны. Включение не зависит от **DEV** или NODE_ENV. При подключении настоящего сервера достаточно заменить транспорт в src/api/request.ts.

Проверки: 11 API-сценариев на стандартных fetch-классах и ещё 11 на whatwg-fetch, который используется React Native. Оба набора проходят с NODE_ENV=production, включая тест без доступа к сети. ESLint, TypeScript, форматирование, полный экспорт приложения и отдельные production-бандлы с импортированным API для Android/iOS прошли. На устройстве и в Hermes пока не запускалось.

Видео пока null: стоковые ролики добавим вместе с плеером на день 7. Длительности уроков пока демонстрационные. ## День 3 — 27 октября 2026

Каталог подключён через TanStack Query: карточки шести курсов, тренер, дисциплина, уровень, количество уроков и длительность. Используется FlatList. Есть загрузка, пустой каталог, ошибка с повторной попыткой и обновление свайпом. При ошибке фонового обновления предыдущие данные остаются видимыми.

Запрос получает AbortSignal, свежие результаты кешируются на пять минут. Возвращение в активное приложение обновляет устаревшие запросы. Для демо-API используется networkMode: always, чтобы локальные обработчики работали и без сети.

Проверки: lint, format:check, typecheck и 25 тестов проходят. В браузерном превью загружены все шесть карточек. Экспорт iOS/Android/web проверен. На настоящем телефоне каталог пока не проверялся: ошибку открытия Expo Go отложили по просьбе пользователя.

## День 7 — 28 октября 2026

expo-video: воспроизведение с обычными контролами, Play/Pause, загрузка и повторная попытка. Урок можно отметить пройденным и снять отметку; досмотр тоже отмечает его автоматически. Прогресс виден в карточке курса, на его экране и в списке уроков. Прохождение всех уроков переносит курс в Completed, снятие отметки возвращает в In progress.

Redux хранит позиции и последний просмотренный урок. На главной есть Continue watching: открывает незаконченный урок с сохранённого времени, а после его прохождения выбирает следующий. При уходе с экрана и сворачивании приложения плеер ставится на паузу. Следующий урок заменяет текущий экран.

Для демо используются два коротких стоковых ролика: [Billy Llano / Pexels](https://www.pexels.com/video/horses-running-in-the-countryside-11011917/) и [RDNE Stock project / Pexels](https://www.pexels.com/video/horse-running-8624804/). Подпись Demo stock footage и ссылка на автора есть в плеере. Длительности уроков теперь соответствуют этим клипам; ролики повторяются в демо-курсах. Оба HD-адреса ответили HTTP 200.

Проверки: lint, format:check, typecheck, 43 теста, экспорт iOS/Android/web. В браузере проверены Play/Pause, автоматическая отметка после досмотра, ручные отметки, переход на следующий урок, прогресс 33/67/100%, Continue watching и восстановление позиции 4,1128 секунды. Исправлено восстановление на web: используется также statusChange, поскольку sourceLoad там не приходит. На Android/iPhone плеер пока не проверялся.

Дни 5–7 сделаны по запросу в один день. PR короткие, без шаблона. README и комментарии в коде не добавлялись. Следующий шаг — день 8: AsyncStorage, чтобы списки и прогресс переживали перезапуск; сейчас они хранятся только в текущем сеансе.
